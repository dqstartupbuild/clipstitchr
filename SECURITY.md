# Security Policy

## Supported versions

Security fixes are provided for the current development version of ClipStitchr.

| Version | Supported |
| --- | --- |
| Current `main` branch | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue, discussion, or pull
request.

Use GitHub's private vulnerability reporting for this repository. Include a
clear description, the affected area, steps to reproduce the issue, and the
potential impact. If private reporting is not available, contact the repository
owner privately through GitHub and ask for a secure reporting channel.

We will acknowledge a report as soon as reasonably possible, investigate it,
and coordinate a fix before public disclosure when appropriate.

## Scope

Please report issues that could affect the confidentiality, integrity, or
availability of ClipStitchr or its users. Examples include authentication and
authorization failures, unsafe data access, secret exposure, billing abuse,
rate-limit bypasses, and vulnerabilities in deployed services.

Do not test against production accounts or data that you do not own. Avoid
actions that could interrupt service, create cost, or access another person's
information.
