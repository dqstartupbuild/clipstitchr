# Demo Walkthroughs

These walkthroughs are for first-time user demo videos. Each one starts from a fresh sign-in and moves the person toward the fastest useful setup based on what they already have.

## Demo Rules

- Keep the story simple: "Use what you already have, then fill the gaps."
- Use plain words on camera. Say "creator clip" or "person talking" when UGC may feel unclear.
- Avoid explaining the video engine, storage, queues, or provider details.
- End every walkthrough with one clear result in the library.
- Show the dashboard, library, and finished asset whenever possible.

## Scenario 1: I Have Demo Videos and UGC Clips

### Goal

Help a new user upload both source types, organize them, and create their first Stitchr batch.

### Starting State

- User just signed in.
- User has product demo videos.
- User has UGC clips.
- User wants ready-to-post video ads quickly.

### Play-by-Play

1. Land on the dashboard.
   - Say: "If you already have clips, start by putting everything in one place."
   - Point out the main upload action.

2. Upload the UGC clips.
   - Choose the upload option for UGC.
   - Select a small batch of creator clips.
   - Wait for the clips to save into the library.
   - Say: "These are the clips that grab attention first."

3. Upload the demo videos.
   - Choose the upload option for Demo.
   - Select one or more product walkthrough or product-in-use videos.
   - Link the demo to the right product when prompted.
   - Say: "These are the clips that show what you sell."

4. Open the Library.
   - Show the UGC tab first.
   - Switch to Demo.
   - Say: "Now the clips are sorted, so you are not hunting through folders."

5. Open Stitchr.
   - Select up to 20 UGC clips.
   - Select one Demo clip.
   - Use the product filter if there are demos for more than one product.
   - Say: "Each creator clip gets paired with the same demo."

6. Preview the pairings.
   - Tap through two or three UGC-then-Demo previews.
   - Trim only if a clip has obvious dead space.
   - Say: "This is the whole ad flow: attention first, product proof second."

7. Add text.
   - Add one simple overlay such as "This made setup so much easier."
   - Copy it across the batch if the same line works for every version.
   - Say: "You can keep one message across the whole batch or edit each version."

8. Create the stitches.
   - Click Stitch.
   - Show the progress state.
   - Wait for the saved outputs.

9. Open the Library Stitches tab.
   - Show the finished outputs.
   - Download one.
   - Mark one as posted if the demo includes the publishing follow-up.
   - Say: "You now have multiple finished videos from the clips you already had."

### Done State

- UGC clips are saved in the UGC library.
- Demo videos are saved in the Demo library.
- At least one finished Stitchr output is saved in Stitches.
- The user understands that Stitchr is the fastest path when both source types already exist.

## Scenario 2: I Have Demo Videos, No UGC Clips, and I Already Have an Avatar

### Goal

Help a user create UGC-style source clips with their existing avatar, then pair those clips with product demos.

### Starting State

- User just signed in.
- User has product demo videos.
- User has no UGC clips.
- User already has an avatar with at least one avatar photo.

### Play-by-Play

1. Land on the dashboard.
   - Say: "You have the product footage. Now we need a few creator-style clips to put in front of it."

2. Upload the demo videos.
   - Choose Demo upload.
   - Add the product demos.
   - Link them to the product.
   - Say: "This gives every future video a clear product moment."

3. Open the Library Avatars tab.
   - Show the existing avatar.
   - Confirm there is at least one avatar photo.
   - If needed, set this avatar as the default avatar.
   - Say: "This gives ClipStitchr a person to use when it creates new source clips."

4. Open Clipr.
   - Choose the saved product.
   - Choose the avatar.
   - Pick Reaction or B-roll.
   - Use Reaction when the demo needs a quick human hook.
   - Use B-roll when the demo needs lifestyle or context footage.
   - Say: "We are making short clips that can act like UGC."

5. Generate a Clipr clip.
   - Start with one Reaction clip.
   - Let it finish.
   - Save it to the library.
   - Say: "This is now usable in Stitchr just like an uploaded creator clip."

6. Generate one more option.
   - Create a B-roll clip or another Reaction clip.
   - Save it to the UGC library.
   - Say: "Two or three options give you room to test different openings."

7. Open the Library.
   - Show Demo.
   - Show UGC.
   - Confirm the Clipr outputs appear as UGC-compatible clips.

8. Open Stitchr.
   - Select the new Clipr UGC clips.
   - Select one product demo.
   - Preview the UGC-then-Demo flow.

9. Add text and create stitches.
   - Use a simple overlay tied to the product benefit.
   - Click Stitch.
   - Save and download the best output.
   - Say: "You started with demos only, and now you have complete ad variants."

### Done State

- Demo videos are saved.
- Existing avatar is confirmed and ready.
- At least one Clipr output is saved as a UGC-compatible clip.
- At least one finished Stitchr output is created from Clipr plus Demo.

## Scenario 3: I Have Demo Videos, No UGC Clips, and No Avatar Yet

### Goal

Help a user create their avatar first, then use it to generate UGC-style clips for Stitchr.

### Starting State

- User just signed in.
- User has product demo videos.
- User has no UGC clips.
- User has no avatar.

### Play-by-Play

1. Land on the dashboard.
   - Say: "You already have product footage. The missing piece is a person ClipStitchr can use for new source clips."

2. Upload the demo videos.
   - Choose Demo upload.
   - Add the product demos.
   - Link them to a product.

3. Open the Library Avatars tab.
   - Choose photo upload.
   - Upload one or more clear photos of the person.
   - Create a new avatar name.
   - Save the avatar.
   - Say: "This saves the person once, so you do not have to set them up every time."

4. Review the avatar.
   - Show the avatar photo.
   - Set the avatar as default if that option is part of the demo.
   - Keep the explanation simple: "This is the person we will reuse."

5. Optional: Generate extra avatar photos.
   - Choose 1, 3, or 5 outputs.
   - Pick UGC style.
   - Add a simple scene like "holding the product at home" if useful.
   - Save the generated photos.
   - Say: "More photos gives the app more ways to create natural-looking clips."

6. Open Clipr.
   - Choose the saved product.
   - Choose the new avatar.
   - Pick Reaction or B-roll.
   - Generate one clip.

7. Save the Clipr output.
   - Confirm it appears in the UGC library.
   - Say: "Now you have your first creator-style source clip."

8. Open Stitchr.
   - Select the new UGC-compatible clip.
   - Select the product demo.
   - Preview the flow.

9. Add text, stitch, and download.
   - Add one clear overlay.
   - Create the stitch.
   - Download the finished video.

### Done State

- Demo videos are saved.
- A new avatar is created.
- At least one Clipr clip is saved as UGC-compatible footage.
- At least one Stitchr output is created.

## Scenario 4: I Have No Avatars, No Demos, and No UGC Clips, So I Want Carousels

### Goal

Help a completely empty user create useful carousel content with Swipr instead of waiting until they have video assets.

### Starting State

- User just signed in.
- User has no avatar.
- User has no demo videos.
- User has no UGC clips.
- User still wants something they can post.

### Play-by-Play

1. Land on the dashboard.
   - Say: "If you do not have videos yet, start with a carousel. You can still make something useful today."

2. Open Settings.
   - Create a product.
   - Add the product name.
   - Add the website URL if available.
   - Add plain product details if the website is not enough.
   - Save the product.
   - Say: "This gives the carousel something real to talk about."

3. Open Swipr.
   - Choose the saved product.
   - Keep the slide count small for the first demo, such as 3 to 5 slides.
   - Say: "We will make a simple swipeable post first."

4. Choose backgrounds.
   - Pick saved backgrounds from the background library.
   - Or generate AI backgrounds from the product context.
   - Or upload clean product or lifestyle photos if available.
   - Say: "You only need enough visual variety to make the slides feel intentional."

5. Generate or write slide text.
   - Click the generate text action if available.
   - Review the first slide hook.
   - Edit the wording so it sounds natural.
   - Say: "The text should feel like something a real person would say."

6. Preview the carousel.
   - Step through each slide.
   - Check that the text is readable.
   - Keep the message direct.

7. Save the Swipe.
   - Save the editable carousel project.
   - Open the Library.
   - Show the Swipes tab.

8. Download the carousel.
   - Download the current saved version.
   - Say: "This gives you a post today while you collect videos for Stitchr later."

### Done State

- A product is saved in Settings.
- A Swipe is saved in the Swipes library.
- The user has a downloadable carousel even with no video or avatar assets.

## Scenario 5: I Want to Set Up Automation

### Goal

Help a user turn on daily drafts and choose which tools ClipStitchr should use automatically.

### Starting State

- User is signed in.
- User wants daily draft creation.
- Best results require saved product context.
- Avatar-based automation needs a default avatar and at least one avatar photo.
- Stitchr automation works best when the library already has UGC-compatible clips and demos.
- Swipr automation needs a saved product and a saved background.

### Play-by-Play

1. Open Settings.
   - Say: "Automation works best after your workspace knows what you sell and what assets it can reuse."

2. Save a product first.
   - Add or confirm the product in Settings.
   - Include product details, audience details, and a website URL when available.
   - Set the product as default if there are multiple products.
   - Say: "This keeps the daily drafts focused on the right offer."

3. Confirm source assets.
   - For Stitchr: make sure at least one UGC-compatible clip and one Demo clip exist.
   - For Clipr: make sure there is a default avatar with at least one photo.
   - For Avatar Photo: make sure there is a default avatar.
   - For Swipr: make sure there is a saved product and at least one saved background.
   - For Swapr: use it only when Swapr automation is enabled in the product build.

4. Open the Automation panel.
   - In Settings, find Automation.
   - Show the Daily drafts section.
   - Point out the run window: 09:00-13:00 UTC.
   - Say: "This is when ClipStitchr looks for daily draft work."

5. Enable automation.
   - Click Enable.
   - Say: "This turns daily drafts on."

6. Choose tools.
   - Check Stitchr for automatic stitched draft ideas.
   - Check Clipr for new UGC-style source clips.
   - Check Avatar Photo for fresh avatar photos.
   - Check Swipr for carousel drafts.
   - Leave unchecked anything the user does not want generated.
   - Say: "Only choose the tools you actually want in your library."

7. Pick Clipr mode.
   - Choose Reaction for quick human hook clips.
   - Choose B-roll for lifestyle or context clips.
   - Choose the option that best matches the product.

8. Pick Stitchr text style.
   - Choose Any for variety.
   - Or choose one style if the brand needs a consistent look.
   - Pick text and background colors if needed.
   - Say: "These settings guide the text that appears on automated Stitchr drafts."

9. Save automation settings.
   - Click Save.
   - Confirm the settings stay enabled after saving.

10. Show where drafts appear.
    - Open the Library.
    - Explain that finished items appear in their normal tabs: UGC, Stitches, Swipes, and Avatars.
    - Say: "Automation does not create a separate inbox. It fills the same library you already use."

### Done State

- Automation is enabled.
- The user selected the tools they want.
- Clipr mode and Stitchr text style are set.
- Product and source prerequisites are clear.
- The user knows where automated drafts will appear.

## Scenario 6: I Want to Research a Public Social Post

Select Guppy Calisthenics in the dashboard product picker. Paste one public TikTok or Instagram video or slideshow URL into Hook Lab, wait for the saved post to finish analyzing, then open its report. Confirm the dialog shows the caption, ordered on-screen text, expressions, body language, object placement and movement order, public metrics, likely meaning, recreation essentials, and a complete timestamped play-by-play. Choose **Use this format**, confirm the Guppy script appears in the same dialog, edit one field, save it, and copy it. Switch the global product to Bloomin, regenerate, and confirm the new script targets Bloomin. Then open the Hook Library tab separately, search for one phrase, filter by category, move to the next page, and copy one result.

## Recommended Demo Order

1. Full library setup: UGC plus Demo into Stitchr.
2. Demo plus existing avatar into Clipr, then Stitchr.
3. Demo plus new avatar into Clipr, then Stitchr.
4. Empty workspace into Swipr carousel.
5. Analyze a public social post in Hook Lab.
6. Automation setup after assets and product context exist.
