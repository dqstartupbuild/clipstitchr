# Clip Score Feature Guide

Clip scores help ClipStitchr users answer one practical question:

> Know which clips are worth using before you waste time posting.

The MVP adds scoring to uploaded UGC and Demo clip analysis. It does not add
pricing, practice drills, or A/B rescoring yet. Finished Stitch scoring now
lives in the dedicated Stitch Score feature.

## Product Angle

ClipStitchr already turns a library of UGC, demos, Clips, Swaps, Swipes, and
Stitches into finished content. The scoring feature makes the library easier to
act on before editing starts.

The user-facing promise is simple:

- Upload a UGC clip or product demo.
- Let ClipStitchr describe and score it.
- See whether the clip is worth using, good with a trim, needs a quick fix, or
  should be skipped for now.
- Open clip details to see the reason, best use, strengths, and fixes.
- Use those scores while choosing clips for Stitchr.

## Implemented MVP

The current implementation stores one optional `performanceScore` on each video
clip. The score is generated by the upload-analysis provider worker and saved as
read-only analysis metadata.

Stored fields:

- `overall`: 0-100
- `hook`: 0-100, optional
- `cameraPresence`: 0-100, optional
- `pacing`: 0-100, optional
- `clarity`: 0-100, optional
- `platformFit`: 0-100, optional
- `stitchFit`: 0-100, optional
- `summary`: one short reason for the score
- `bestUse`: where this clip fits best
- `strengths`: up to 3 short strengths
- `fixes`: up to 3 short fixes

The UI turns `overall` into simple labels:

- `80+`: Worth using
- `65-79`: Good with a trim
- `50-64`: Needs a quick fix
- `<50`: Skip for now

## Model Decision

The user requested Replicate-hosted OpenAI models first, defaulting to
`openai/gpt-5-mini` with an environment override for other GPT models when they
support the needed analysis.

The implementation follows that for poster/image upload analysis:

- `REPLICATE_UPLOAD_ANALYSIS_MODEL_ID` defaults to `openai/gpt-5-mini`.
- The value can be overridden to another Replicate model ID.

Full-video analysis still defaults to Gemini:

- `REPLICATE_UPLOAD_VIDEO_ANALYSIS_MODEL_ID` defaults to
  `google/gemini-3-flash`.
- This path is used when ClipStitchr sends the actual video, not just a poster
  image.

Reason: as of the implementation check, OpenAI's GPT-5 mini API documentation
lists text and image input, but not video input. The OpenAI vision guide also
documents image inputs for analysis. Replicate's `openai/gpt-5-mini` page
likewise presents it as a text/image model, while Replicate's
`google/gemini-3-flash` page lists video support. Because true clip scoring
needs full-video understanding, Gemini remains the full-video fallback.

## Backend Flow

1. Upload analysis prompts ask the provider to return `performanceScore`.
2. The parser validates and clamps numeric scores to 0-100.
3. The provider worker passes the parsed score into the Convex mutation.
4. Convex stores the score on the `videoClips` record.
5. Clip document mappers include the score in `VideoClip` and
   `VideoClipMetadata`.
6. Dashboard clip cards and details dialogs render the score when present.

This is analysis metadata, not user-editable metadata. User clip metadata edits
do not overwrite the score.

## Abuse and Rate Limits

The feature uses the existing upload analysis surfaces:

- poster/image analysis limits for `REPLICATE_UPLOAD_ANALYSIS_MODEL_ID`
- full-video analysis limits for `REPLICATE_UPLOAD_VIDEO_ANALYSIS_MODEL_ID`
- provider-worker rate gates before paid provider calls

No new unauthenticated backend route, provider call, or rate-limit bucket was
introduced. `docs/backend/rate-limits.md` documents the default model split.

## Future Phases

The original idea has good follow-on directions, but they should be separate
features:

- Rescore a trimmed clip and show before/after score movement.
- Use real post-performance history to improve score calibration.
- Show a cautious "predicted lift" only after there is a real internal basis
  for the estimate.
- Generate daily 3-minute practice drills for creator clips.
- Add platform-specific scoring profiles for TikTok, Reels, and Shorts.
- Generate alternate hook scripts from the weakest score dimension.
- Rank selected Stitchr UGC clips by score while keeping user choice explicit.

Do not ship numeric retention-lift claims until the product has enough
ground-truth performance data or a clearly documented evaluation method.
